# Security policy

Nod can approve commands on your computer, so security reports are taken seriously.

## Reporting a vulnerability

Please **do not open a public issue**. Report it privately through
[GitHub security advisories](https://github.com/NilsMorczinietz/nod/security/advisories/new).
You'll get an answer within a week. Once a fix is released, the advisory is published with credit
(if you want it).

## Supported versions

Only the latest release gets fixes. Update with `nod update` and the in-app updaters.

## Design notes

How tokens, pairing and approvals are protected is described in
